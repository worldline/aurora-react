# Aurora React

Aurora React is Worldline's React component library for the Aurora Design System.

## Install

```sh
npm install @worldline-official/aurora-react
```

The package includes its styles and fonts. It depends on
`@worldline-official/aurora-design-tokens` at an exact, pinned version.

## Use

```tsx
import { Button } from "@worldline-official/aurora-react/components";
import "@worldline-official/aurora-react/styles.css";
```
