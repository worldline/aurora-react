# Button

A versatile button component built with **React Aria** for full accessibility
support.

## Features

- 🎨 **Three variants**: Primary, Secondary, and Danger
- 📏 **Three sizes**: Small, Medium, and Large
- 🌓 **Dark mode support**: Automatically adapts to light and dark themes
- ♿ **Accessible**: Built with React Aria for keyboard navigation, screen
  readers, and ARIA attributes
- 🎯 **Interactive states**: Hover, pressed, focus, and disabled states
- 📱 **Fully responsive**: Adapts to all screen sizes with optimized touch
  targets for mobile

## Usage

```tsx
import { Button } from '@worldline/aurora-react/components'

const MyComponent = () => (
  <Button variant="primary" onPress={() => console.log('Pressed!')}>
    Click me
  </Button>
)
```

## Responsiveness

The Button component is fully responsive and adapts to different screen sizes
using a mobile-first approach.

### Icon-Only Buttons

Icon-only buttons are supported for all variants. Use an icon as the child and
provide an `aria-label` for accessibility:

```tsx
import { AddIcon, Button } from '@worldline/aurora-react/components'

const Example = () => (
  <Button variant="primary" aria-label="Add">
    <AddIcon aria-hidden />
  </Button>
)
```

<Canvas of={ButtonStories.IconOnlyPrimary} />

**Accessibility:** Always provide a descriptive `aria-label` for icon-only
buttons so screen readers can announce the button's purpose. The icon should
have `aria-hidden` to avoid duplicate announcements.

### Breakpoint Behavior

| Breakpoint  | Width   | Button Behavior                                                |
| ----------- | ------- | -------------------------------------------------------------- |
| **Mobile**  | ≤640px  | Full-width buttons with larger touch targets (min 44px height) |
| **Small**   | ≥640px  | Auto-width with minimum width constraints                      |
| **Tablet**  | ≥768px  | Increased spacing and padding                                  |
| **Desktop** | ≥1024px | Enhanced hover effects with elevation and transforms           |
| **XL**      | ≥1250px | Larger font sizes for large buttons                            |

### Mobile Optimizations

- **Full-width layout** on mobile (≤640px) for easier tapping
- **Minimum touch targets** of 44px (iOS) to 52px for better accessibility
- **Reduced icon gaps** on small screens for better visual balance
- **No hover effects** on touch devices (uses `@media (hover: hover)`)

### Testing Responsiveness

Use the Storybook viewport addon (toolbar icon) to test buttons at different
screen sizes:

1. Select different viewports from the dropdown
2. Observe how buttons adapt their size, padding, and layout
3. On mobile viewport, buttons become full-width
4. On desktop viewport with mouse, see enhanced hover effects

### Code Example

```tsx
// Button automatically adapts to screen size
<Button variant="primary" size="medium">
  Responsive Button
</Button>

// On mobile: full-width, larger touch target
// On tablet+: auto-width with minimum constraints
// On desktop: enhanced hover effects
```
